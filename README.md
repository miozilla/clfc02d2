# clfc02d2 ⚡🌉⌚
clfc02d2 : AWS Lambda Amazon EventBridge # Monitoring # EC2 # CloudWatch # CLF-C02


## Objective
- Invoke AWS Lambda function to log the state of an Amazon EC2 instance.
- Configure Amazon EventBridge rule to monitor the state of the EC2 instance by using a Lambda function.
